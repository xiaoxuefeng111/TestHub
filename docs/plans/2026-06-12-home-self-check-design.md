# Home 自检按钮设计

> **Goal:** 在 Home 页面增加一个手动自检入口，帮助用户快速判断“服务器错误”是否来自后端 8000 / dev-login 链路异常。

**Architecture:** 仅修改前端 Home 页面。点击按钮后，使用一次独立的 `axios.post('/api/auth/dev-login/')` 做检测，不复用现有认证状态，不改后端接口。结果通过弹窗展示成功/失败和简要原因。

**Tech Stack:** Vue 3、Element Plus、axios、vue-i18n

---

## 方案

### 入口
- PC：放在 Home 右上角操作区，和语言/用户并列
- Mobile：放进右上角下拉菜单

### 检查内容
- 认证接口 `/api/auth/dev-login/` 是否可访问
- 返回是否为 2xx 且携带完整登录数据
- 失败时提示后端未启动或接口异常

### 展示
- 使用 `el-dialog` 显示检测中/成功/失败状态
- 成功显示“后端服务正常，可以进入各模块”
- 失败显示“请确认 127.0.0.1:8000 已启动”

### 风险控制
- 不改现有卡片跳转逻辑
- 不把自检做成自动轮询
- 不新增后端健康检查接口
